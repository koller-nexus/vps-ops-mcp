# Contract: Root `LICENSE`

## Location

- Path: `LICENSE` (repository root)
- Format: plain text MIT license

## Required tokens

| Token | Maps to |
|-------|---------|
| `MIT License` | FR-003 |
| `Permission is hereby granted, free of charge` | FR-003 |
| `2026` | copyright year |
| `THE SOFTWARE IS PROVIDED "AS IS"` | FR-003 |

After push, GitHub license metadata MUST report SPDX `MIT` (operator check in [github-host.md](./github-host.md)).
